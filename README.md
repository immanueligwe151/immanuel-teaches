# Immanuel Teaches

## Introduction

Welcome to **Immanuel Teaches**!

Immanuel Teaches is a tutoring platform for KS3, GCSE and A-Level students based in the UK. After having taught in UK schools for at least over a year, I'm now offering personalised instructions to students in Mathematics, Computer Science/ICT and Sciences at various levels.

This repository contains the source code, documentation, and other resources used in building and maintaining the project.

## Project Overview

**Immanuel Teaches** is an online tutoring platform designed to make learning more accessible, engaging, and effective. The platform aims to connect students with quality educational resources and personalised tutoring support to help them improve their understanding of various subjects and achieve their academic goals.

The website will provide a space where students can access tutoring services, explore learning materials, and receive guidance tailored to their educational needs.

The goal of this project is to create a user-friendly learning environment that simplifies the process of finding academic support while making quality education more accessible to everyone.

This project is currently under development, with new features and improvements being introduced as development progresses.

## Features

The platform aims to provide the following features:

### Student Features
- User registration and authentication.
- Personalised student dashboard.
- Access to available subjects and tutoring services.
- Online tutoring session booking.
- Access to educational resources and study materials.
- Interactive quizzes and assessments.
- Learning progress tracking.
- Responsive and user-friendly interface.

### General Website Features
- Tutor profile and professional information.
- Display of tutoring packages and services.
- Testimonials and student reviews.
- Contact and enquiry form.
- Frequently Asked Questions (FAQs).
- Mobile-friendly and responsive design.

### Administrative Features
- Admin dashboard.
- Student account management.
- Tutoring session management.
- Educational content management.
- Course and subject management.
- Payment and transaction management.

*Note: Features are subject to change as development progresses.*

## Technologies Used

The following technologies and tools are being used in this project:

- **Frontend:** Next.js, Typescript, Tailwind CSS
- **Backend:** SpringBoot, Java
- **Database:** MySQL
- **Version Control:** Git and GitHub
- **Development Environment:** Visual Studio Code
